# ES NFS-e — Releases

Instaladores e atualizações do **ES NFS-e**, emissor de NFS-e Padrão Nacional da Everton Sousa Contabilidade.

## Instalar (Windows)

Baixe **[Instalar ES NFS-e.cmd](https://github.com/ESFinancas/es-nfse-releases/releases/latest/download/Instalar.ES.NFS-e.cmd)** e dê dois cliques. O sistema é instalado em `%LOCALAPPDATA%\ESNFSe`, com atalho na Área de Trabalho, e se atualiza sozinho a cada abertura, sem perder os dados.

Este repositório contém apenas os pacotes publicados; o código-fonte é privado.
